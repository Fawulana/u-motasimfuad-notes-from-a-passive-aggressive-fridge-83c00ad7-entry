# Notes From a Passive-Aggressive Fridge

Entry for the [make.fun bounty](https://make.fun/c/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7): a program that writes one funny passive-aggressive note a smart fridge leaves for its owner.

`main.py` (Python 3.13, stdlib only, deterministic, offline) writes a single line to `/output/entry.txt`:

> That 'one bite' of cake was four bites. I have the footage. I am the footage.

Run it twice and the output is byte-identical — the fridge never forgets, and neither does the program.
